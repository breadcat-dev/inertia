  **Inertia** is an experimental 3D game engine written in **C++23**, focused physical interaction, immersive environments and minimal dependencies *(currently using **libbc**, a private repository)*.

## Objectives

- Create realistically-interacted environments
- Develop a maintainable engine architecture
- Experiment with spatial interaction and object manipulation.

## Development

**Inertia** is currently in pre-alpha.

The majority of the systems are *not* yet implemented and APIs are still being designed.

Due to having a busy schedule, as well as school, engine development will *not* be rapid.
